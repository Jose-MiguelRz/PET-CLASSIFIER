# 🐶🐱 Clasificador de Perros vs Gatos
Proyecto Final — Inteligencia Artificial | UDLAP Fall 2024

## Descripción
Clasificador de imágenes binario usando Transfer Learning con MobileNetV2.
Alcanza 98.19% de accuracy en el conjunto de prueba.

## Cómo ejecutar
1. Abre el notebook en Google Colab
2. Runtime → Change runtime type → GPU (T4)
3. Ejecuta todas las celdas en orden

## Tecnologías
- TensorFlow / Keras
- MobileNetV2 (Transfer Learning)
- Gradio (interfaz web)
- Scikit-learn (comparación SVM)

## Resultados
| Método | Accuracy |
|--------|----------|
| SVM (baseline) | 61.20% |
| MobileNetV2 | 98.19% |
